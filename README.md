# Toyo Specialty Coffee + Matcha Website

This website recreates the design from the ToyoSite PDF.

## 📁 Files Included

- `index.html` - Main website structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive features and smooth scrolling
- `generate-placeholders.html` - Tool to generate placeholder images
- `images/` - Folder for all website images

## 🚀 Quick Start

1. **Generate Placeholder Images:**
   - Open `generate-placeholders.html` in your web browser
   - Click "Generate All Placeholders" button
   - All images will download to your Downloads folder
   - Move all downloaded images to the `images/` folder

2. **View the Website:**
   - Open `index.html` in your web browser
   - The website will display with placeholder images

3. **Replace Placeholders:**
   - Replace the placeholder images with your actual photos (see list below)
   - Keep the same filenames or update the paths in `index.html`

## 🔧 Customization

### Update Text Content:
Edit `index.html` to change any text, add menu items, or update location information.

### Modify Colors:
Edit `styles.css` - colors are defined in the CSS custom properties and throughout the stylesheet.

### Add Menu Items:
Replace the menu placeholder section (lines 82-91 in index.html) with your actual menu content.

### Add Calendar/Events:
Replace the calendar placeholder (lines 118-125 in index.html) with a calendar widget or event listing.
